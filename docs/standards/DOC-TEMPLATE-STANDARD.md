# 文档模板标准（DOC-TEMPLATE-STANDARD）

## 概述
本文档定义项目内 Markdown 模板的统一格式规范，确保所有文档可读、可审计、可自动检查。

## 通用规则
1. 所有模板必须使用 UTF-8 编码，扩展名为 `.md`。
2. 标题层级从 `#` 开始，不允许跳级。
3. 一级标题应唯一，且与文档主题一致。
4. 列表、表格、代码块语法必须符合 Markdown 标准。
5. 文档内容需保持模板化，不包含项目私有信息。

## 元数据头部
每个模板文件都必须包含 YAML Front Matter：

```yaml
---
项目名称: <项目名>
创建日期: <YYYY-MM-DD>
状态: <草稿|审核中|已发布|已归档>
负责人: <角色/姓名>
---
```

可选字段（按需添加）：
- `关联文档`
- `版本`
- `审核人`

## 模板使用指南
1. 从 `docs/templates/` 复制目标模板到项目 `docs/` 根目录。
2. 将占位符 `<...>` 替换为项目实际信息。
3. 按 Gate 阶段补齐必填章节后再进入下一阶段。
4. 新增模板后必须同步更新：
   - `docs/standards/DOC-LIBRARY.json`
   - `DOC-REGISTRY.json`
5. 由 CI 工作流执行格式校验与注册表一致性校验。
